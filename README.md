## ✨ What is Pixel Creator?

Pixel Creator is a browser-based 2D game engine that makes game creation accessible to
everyone.

- 🌐 **Web-first** — Open the editor and start creating
- 🎯 **Beginner-friendly** — Build visually instead of writing code
- 🧩 **Objects and components** — Compose your game from simple reusable pieces
- 🔗 **Visual scripting** — Create behaviours by connecting nodes
- 🗺️ **Scenes, sprites, tilemaps and prefabs** — Build complete 2D worlds
- ▶️ **Play and Preview** — See your game as you build it

## Getting started

Open **[editor.pixelcreator.io](https://editor.pixelcreator.io)** — a starter scene is
already waiting. Click something, move it, press Play.

Then take ten minutes with **[Getting started](docs/user/getting-started.md)**.

## Contributing

Pixel Creator is plain JavaScript — ES modules, no build step, no dependencies, nothing to
install. Clone it, serve it, open a page, and you are working on the engine. Bug fixes,
editor polish, new components, new graph nodes, documentation and demos are all welcome, and
[CONTRIBUTING.md](CONTRIBUTING.md) has everything you need to send your first pull request.

Found a problem? [Open an issue](https://github.com/Sharkou/PixelCreator/issues).
