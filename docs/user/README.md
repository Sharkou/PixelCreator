# Pixel Creator — User guide

Everything you need to make a game with Pixel Creator. No programming experience assumed.

**[▶ Launch Pixel Creator](https://editor.pixelcreator.io)** — it runs in your browser.
Nothing to install, no account needed.

## Start here

1. **[Getting started](getting-started.md)** — open the editor, move an object, press Play.
2. **[Editor layout](editor-layout.md)** — a tour of every panel and button.
3. **[Objects and components](objects-and-components.md)** — the two ideas the whole engine
   is built from.
